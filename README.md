# 🎓 Student Management System in C

A powerful and user-friendly **Student Management System** developed in **C Programming Language** using **Structures** and **File Handling**. This project enables efficient management of student records through a menu-driven interface while ensuring permanent data storage.

---

## 📌 Project Description

Managing student information manually can be time-consuming and error-prone. This Student Management System provides a simple and efficient solution for storing, updating, searching, and managing student records.

The application uses **binary file handling** to maintain data permanently, allowing records to persist even after the program is closed.

---

## ✨ Features

✅ Add New Student Records

✅ Display All Student Records

✅ Search Student by Roll Number

✅ Update Existing Student Information

✅ Delete Student Records

✅ Permanent Data Storage Using Files

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/Student-Management-System.git
```

### Navigate to Project Folder

```bash
cd Student-Management-System
```

### Compile the Program

```bash
gcc student_management.c -o student_management
```

### Run the Program

#### Windows

```bash
student_management.exe
```

#### Linux / macOS

```bash
./student_management
```
